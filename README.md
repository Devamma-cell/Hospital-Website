# CarePoint Hospital Website (Frontend Demo)

## Run
Open `index.html` in a browser. Bootstrap is loaded from its CDN, so internet access is needed for Bootstrap styling and fonts.

## Demo admin login
- Username: `admin`
- Password: `admin123`

## Included
- Responsive homepage with About, Departments, Doctors, Services, Facilities, Testimonials, Gallery, Health Tips, and Contact sections
- Patient account registration and login (demo)
- Patient portal showing the logged-in patient's appointment status
- Appointment request form with department/doctor selection
- Patient record creation from appointment requests
- Admin dashboard for appointment status, doctors, departments, patients, and enquiries
- Contact enquiry form
- Browser `localStorage` persistence

## Important
This is a **frontend-only demonstration**. Data is stored in the current browser and is not shared between users or devices. The demo admin and patient login are not secure. Patient passwords are stored in browser LocalStorage for demonstration only. Do not use it for real patient data or production healthcare operations. A real deployment needs a secure backend, database, authentication/authorization, server-side validation, privacy controls, HTTPS, audit logs, and applicable healthcare/legal compliance. Replace demo hospital details and illustrative content before publishing.
